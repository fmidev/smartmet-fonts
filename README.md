# smartmet-fonts

Part of [SmartMet Server](https://github.com/fmidev/smartmet-library-spine). See the [SmartMet Server documentation](https://github.com/fmidev/smartmet-library-spine) for an overview of the ecosystem.

## Overview

Weather symbol fonts used by SmartMet rendering tools. These fonts contain meteorological symbols for use in weather map products and visualizations.

## Usage

Used by [smartmet-qdcontour](https://github.com/fmidev/smartmet-qdcontour), [smartmet-qdcontour2](https://github.com/fmidev/smartmet-qdcontour2), and other SmartMet rendering tools.
